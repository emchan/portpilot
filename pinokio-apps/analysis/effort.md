# Porting effort — all apps re-ranked, easiest first

Companion to [`results/pinokio-apps.md`](../results/pinokio-apps.md), [`analysis/cpu.md`](cpu.md), [`analysis/kernels.md`](kernels.md), [`analysis/quantization.md`](quantization.md), [`analysis/models.md`](models.md), and [`analysis/flows.md`](flows.md). Snapshot: `main` tips recorded on 2026-11-20; each project links to its analysed commit.

## Ranking method

The base is the study's `difficulty_score` in [`results/pinokio-apps.md`](../results/pinokio-apps.md). It is adjusted here with evidence cross-checked from [`analysis/cpu.md`](cpu.md) (+6 hard CUDA/TensorRT blockers, +4.5 Apple-only runtimes, +2 missing non-GPU launcher branch), the flow dtypes (+1.5 for FP8/packed-4bit weights), direct `torch.cuda` calls (+1), GPU-only quantisers/runtimes (+0.5 each) and Apple MPS branches (+0.25). The same score bands as the original study produce the difficulty level. This makes the order *effort-based* rather than alphabetical; the original level is retained in the per-app reports.

**Precisions used** merges explicit source-level dtype/Cast signals from [`quantization.md`](quantization.md) with the weight dtypes of the reconstructed safetensors GEMMs in [`flows.md`](flows.md). **Models used** are the non-wheel Hugging Face repositories pulled by the launcher, detailed in [`models.md`](models.md).

## Reading the extremes

- **Easiest:** ai-video-composer, bolt, browser-use, controlyourself, ditto, errortest, invoke, mcp, open-webui, openui, sillytavern, vibevoice-realtime — mostly web UIs, external model runners or tools with no local GEMM workload, so no GPU kernel needs a CPU replacement; `vibevoice-realtime` is the only one with a (small) BF16 checkpoint flow.
- **Hardest:** TRELLIS, StreamDiffusion, hunyuanvideo, comfy, ai-toolkit, Ultimate-TTS-Studio, echomimic2, yue, wan, RuinedFooocus, Allegro-txt2vid, ACE-Step — TensorRT/CUDA Graphs, compiled CUDA extensions, explicit NVIDIA guards, or very large FP8/BF16 diffusion checkpoints.
- Apps in the middle are usually installable on CPU but need attention-backend substitution and AVX512/AMX hardware to be usable at the default checkpoint size; see [`cpu.md`](cpu.md) for the per-app verdict and optimizations.
