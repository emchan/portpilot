## Notes on interpretation

- **GGUF** entries are K-quantized llama.cpp checkpoints (`Q4_0`, `Q8_0`); they are portable at the file level but their launcher may still install a CUDA-only loader.
- **PyTorch** here means `.safetensors`, `.bin`, `.pt`, `.pth` or `.ckpt` checkpoints requested by the launcher. Many such repos also contain config/tokenizer files that are not listed.
- **FP8 / NF4 / INT8** models are pre-quantized weights, so no quantization library is necessarily invoked at port time, but a compatible loader is still required.
- **unspecified** precision means the launcher names the model repo but not a precision-bearing filename; the upstream checkpoint controls the actual dtype.
