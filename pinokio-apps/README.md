# Pinokio apps study

This is an experiment to better understand the software (SW) dependencies across a collection of AI apps — which libraries they pull in, and how those dependencies shape how portable each app is to different hardware platforms.

We chose [Pinokio](https://github.com/pinokiofactory) as the source collection because it is a reasonably good, broad set of usable AI apps that target multiple platforms. That mix makes it useful for seeing where dependencies are cross-platform versus tied to a single vendor's GPU stack.

All outputs are written into the [`results/`](results/) directory. The resulting list in [`results/pinokio-apps.md`](results/pinokio-apps.md) is autogenerated from the prompt in [`pinokio-port.md`](pinokio-port.md), which walks through every repository in the `pinokiofactory` GitHub organization, records its dependencies and platform signals, and builds the summary table. To reproduce or update the study, simply ask OpenCode to execute the plan in [`pinokio-port.md`](pinokio-port.md).

Alongside the summary table, the prompt also asks for a detailed report per app in `results/`, with one analysis per package covering its name, description, original git URL, declared dependencies, supported platforms, and CUDA footprint (kernel count, CUDA vs non-CUDA lines of code, and CUDA-related functions used).

This is **work in progress**. As the prompt gets more sophisticated and the agent is steered better, both the list and the insights drawn from it will improve.
